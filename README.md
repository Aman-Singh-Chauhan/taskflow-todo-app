# 🚀 TaskFlow Todo App

A modern Todo App made using HTML, CSS, and JavaScript.

## Features

- Add/Delete/Edit Tasks
- Mark Tasks Completed
- Task Priority Levels
- Daily Completed Counter
- Pending Tasks Counter
- Responsive UI
- Local Storage Support
- Task Filters

## Technologies Used

- HTML
- CSS
- JavaScript
